# Help Directory

## Table of Contents
- [Contents](#contents)

This directory contains the main documentation and release notes for the Single Sign-On library.

## Contents

- `SSO Library.docx`: The main Word document for the library documentation. It describes the architecture, setup, configuration, and usage of the SSO library.
- `SSO Library.pdf`: A PDF copy of the Word documentation for easier distribution and reading without requiring Microsoft Word.
- `changelog.md`: The version history of the library, containing the relevant changes, fixes, and improvements for each released version.

Keep these files up to date whenever the library documentation or versioned behavior changes.
