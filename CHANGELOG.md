With every version, there are some improvements, the improvements are listed below per verion number.
Current Version: 2.0.5

## 2.0.5

- Improved PKCE code-verifier validation and URL-safe Base64 decoding.
- Correctly form-encode token-request parameter values.
- Improved OpenID callback, token and endpoint handling.

## 2.0.4
- Reject login when the id_token can't be verified, instead of silently falling back to userinfo.

## 2.0.3
- Fixed a crash on callback when the state param doesn't resolve to a known state object.

## 2.0.2
- Callback URL no longer keeps a trailing '?' when there are no parameters to append.

## 2.0.1
- Fixed a broken relative-endpoint check that treated every endpoint as relative.

## 2.0.0
- Completely refactored the way the library works. Everything revolves around "state" objects now. A state object is an object that keeps track of an identity which is a set of access/refresh token(s) and a subject (providers unique identifier).
- Removed listener classes/functionality
- Improved the callback handler to be plug and play with the cProviderOpenId class.
- Endpoint parameters can now use absolute OR relative paths
- Added public client compatibility (pbPublicClient)
- Added 'pbForceCodeChallenge' to force a code challenge for confidential clients, identity servers could require this.
- Added 'pbAutoDiscovery' for auto discovery of endpoints. This will load each endpoint from 'psDiscoveryEndpoint' if set, otherwise it will use psSsoHost of the provider (the base url) plus '.well-known/openid-configuration' which is often the default location.
- The introduction of state objects allows for multiple, simultaneously logged in, SSO sessions.
- RSA public key auto loading: the previous versions only allowed for RSA certificates, simple public/private RSA keys will work now too.
- Added 'psScopeParam' which allows for customizing the requested scopes that should be requested for a certain provider.

## 1.0.5
- Automatic loading of the signing keys can now be done by setting the "pbAutoloadCertificates" property to true and filling the "psJWKSEndpoint" property to the JWKS endpoint where the keys can be loaded from.
- Fixed bug regarding the webproperties after Single Sign On process. Userlogin function can now be called via UserLoginSSO.
- Session is now based on AccessToken expiration instead of its own primary key expiration. This fixes the bug regarding the session token of DataFlex expiring before the accesstoken does.

## 1.0.4
- Added functionality to add multiple rotating signing keys (used by Microsoft Entra ID).
- Fixed Proces Pooling issues.
- Fixed WebAppUser.LoginName size from 20 to 255.
- Callback path renamed to "SSOCallback".
- Fixed timing issues (double/multiple cycles).
- Added function to log out of only the application and not the whole provider.
- Fixed issues with 32-bits JWT library. JWT added functionality for flexibility regarding what values go into the token.

## 1.0.3
- Added the JWT library, which is now being used for JWT signature validation. The Introspection server call isn't necessary anymore.
- RSA hashing algorithm is now possible.
- Changed a bit on how the setcookie method is being called. Should make it more stable.
- Made the base64(URL) methods global. They aren't needed from the security package anymore.
- From now on, there aren't version numbers in the directories. Instead the current version is listed at the top of this file.
- There are no more Keycloak errors/warning being generated by doing a invalid accesstoken login attempt.

## 1.0.2
- Fixed issue with not being able to use the SSO over multiple applications
- Cookie duration changed from a set time to 'session'

## 1.0.1
- Added ID_Token as property and cookie.
- Token are now not revoked before logout, but it doesn't redirect anymore. 
- The name of the web application is now changed from 'ssodemo' to 'SSODemo' in the url's inside of the WebApp.src
- The algorithm in the header isn't checked to a hardcoded value. But against the C_$JWTHeaderAlgorithmVal constant.
- Implemented a new UnixTime package to get a function that returns the current unixtime, and more.
